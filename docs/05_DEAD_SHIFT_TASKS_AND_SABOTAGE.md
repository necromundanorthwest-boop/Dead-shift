# Tasks and sabotage

Seven console themes share the same accessible four-contact ordered sequence. Contacts are randomly generated by the server. The next required contact is visibly identified; speed is not the challenge. Server validation requires six seconds total and 0.65 seconds between contacts. This alpha intentionally does not contain seven distinct minigame engines.

| Console | Theme | Contacts | Result |
|---|---|---|---|
| Power | Power coupling | A / B / C / D | Critical progress or clear Blackout |
| Relay | Relay alignment | North / East / South / West | Critical progress |
| Ventilation | Pressure balance | Intake / Bypass / Return / Exhaust | Critical progress or clear Air Failure |
| Lift control | Lift reset | Brake / Cable / Door / Motor | Critical progress |
| Pumps | Sump purge | Drain / Flush / Prime / Seal | Clear Air Failure once |
| Filters | Filter replacement | Release / Remove / Replace / Latch | Add 25 seconds once |
| Security | Signal calibration | Channels 01–04 | Broadcast confirmation once |

Blackout shrinks vision and energizes the marked Generator patch. Air Failure contaminates three connected southern rooms. Neither closes exits. Faults expire naturally or clear by counter-repair. Counter-repair overrides commissioning delay. An active hostile fault prevents another hostile fault from being started. Natural ventilation neglect can coexist with Blackout.

All roles can repair; Infiltrators also have a six-second fake-work action. Observers receive identical WORKING flags. A completed global progress increment proves that someone repaired a system, not that the actor is loyal.
