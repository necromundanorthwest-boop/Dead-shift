# Pixel visual system

The source reference is Underhive Duel's existing `public/assets/ui/tokens.css`: dark iron, bone text, amber interaction, cyan readouts and coral warnings. DEAD SHIFT reuses that palette rather than copying arena composition or character assets.

| Token | Hex | Use |
|---|---|---|
| Void | #101419 | Main background |
| Panel | #1c252c | Steel panels |
| Raised | #29353d | Buttons |
| Bone | #f2e9d7 | Primary text |
| Muted | #bec9cc | Secondary text |
| Amber | #ffca70 | Primary actions / identity marker |
| Cyan | #86dbe8 | Online systems |
| Coral | #ff9b89 | Warnings |

Original canvas primitives create riveted tile flooring, furnace banks, pipes, ventilation units, sump channels, hazard strips and lift plates. Six 12×14 worker patterns vary headgear and silhouettes, with numbered callsigns supplementing accent color. Thick outlines, integer coordinates, nearest-neighbor canvas presentation and restrained animation preserve pixel readability.

HTML typography remains readable and scalable. No external fonts or artwork are fetched. All assets are code-native and included. Social-deduction genre conventions (hidden allegiance, discussion and voting) remain; no astronaut silhouettes, copied map composition or copied task screens are used. Cause-versus-culprit hazards and physical extraction establish the game's identity. The Wheels of Fury racing supplement contributes no rules or imagery.
