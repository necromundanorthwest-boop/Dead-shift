# Information model

| Information | Recipient | Timing | Purpose |
|---|---|---|---|
| Static topology and console positions | Everyone | Always | Navigation |
| Critical progress, commissioning, fault status, clock | Everyone | 10 Hz snapshots | Understand collective pressure |
| Callsign, readiness, connection state | Everyone | Always | Room coordination |
| Other workers' living status | Everyone | Lobby/briefing/meeting/result only | Avoid global active-play death notification |
| Role, task contacts, orders, exposure | Owning worker | Private snapshot | Personal decisions |
| Hostile cooldowns | Infiltrator only | Private snapshot | Ability readiness |
| Nearby actors and visible bodies | Local recipient | Radius + wall visibility | Observation |
| Interaction underway | Nearby observers | During real or fake work | Ambiguous evidence |
| Inspection symptoms | Inspecting worker | On request | Cause without culprit |
| Local event captions | Nearby recipients | Eight active seconds | Incomplete incident cues |
| Votes and allegiance confirmation | Everyone | Resolution | Accountability |
| All allegiances | Everyone | Match over | Debrief |
| Foreign tokens, sabotage ownership, exact hidden causes | Server only | Never serialized | Information boundary |

Dead workers retain a stationary local observer view. There is no free-roaming ghost camera and no in-game communication. Discord silence is socially enforced. The static terrain remains faintly visible as navigation context, but concealed actor data is never transmitted. Fog is a presentation layer over server-side recipient filtering.
